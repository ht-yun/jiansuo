# 中国企业信息自动采集工具

## 一、工具用途

本工具用于查询和保存中国企业在国家企业信用信息公示系统公开展示的信息。

支持的主要信息包括：

- 企业名称、统一社会信用代码、法定代表人、经营状态；
- 企业类型、注册资本、成立日期、登记机关、注册地址、经营范围、所属行业；
- 股东及出资；
- 对外投资；
- 任职信息；
- 经营异常；
- 严重违法失信；
- 官网原文中未映射到主要字段的其他信息。

工具不需要商业 API 密钥，也不会读取或上传 Cookie、账号和密码。默认验证码和安全验证由使用者在官网完成；可选启用超级鹰自动识别。

## 二、运行前准备

使用者电脑需要安装：

1. Windows 10 或 Windows 11；
2. Java 17 或更高版本；
3. Microsoft Edge 浏览器。

如果使用的是已经打包好的版本，不需要安装 Maven。

## 三、启动项目

### 方式一：运行启动文件

双击发布包中的启动文件：

```text
启动项目.bat
```

看到窗口显示项目已启动后，在 Edge 地址栏打开：

```text
http://127.0.0.1:8080/
```

启动窗口不要关闭。关闭窗口会停止项目。

### 方式二：命令行启动

在项目目录打开 PowerShell，执行：

```powershell
java -jar company-profile-query-0.1.0-SNAPSHOT.jar
```

然后访问 `http://127.0.0.1:8080/`。

## 四、首次安装 Edge 验证助手

1. 在 Edge 地址栏打开 `edge://extensions/`。
2. 打开页面左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择发布包中的 `edge-extension` 文件夹。
5. 找到“企业信息验证助手”，建议点击固定图标。

项目或扩展更新后，需要在 `edge://extensions/` 页面点击扩展卡片上的“重新加载”。当前扩展版本为 `0.2.6`。

## 五、使用企业名单查询

### 1. 准备名单

可以使用 CSV 或 XLSX 文件。

推荐格式：

```text
单位名称
北京示例科技有限公司
上海示例贸易有限公司
广东示例制造有限公司
```

如果文件只有一列，系统会自动把第一列当作企业名称。空行会跳过，重复企业会自动去重。

### 2. 导入名单

1. 打开项目首页。
2. 点击“导入企业名单并自动采集”。
3. 选择 CSV 或 XLSX 文件。
4. 等待系统显示企业数量和待采集数量。

系统会优先匹配本地已经确认的企业档案，命中的企业不需要重复查询官网。

### 3. 不导入名单时查询单个企业

在“ 不导入名单时，直接输入企业名称”输入框中填写企业名称，点击“开始自动采集”即可。

系统会创建一个只有一条记录的企业任务，后续流程与批量查询相同。

## 六、开始自动采集

1. 确认 Edge 正在运行，并且已经加载“企业信息验证助手”。
2. 在项目页面点击“开始后台查询”。
3. 扩展会在后台打开国家企业信用信息公示系统，不会主动把官网窗口切到前台。
4. 每家企业只会提交一次查询，扩展会等待官网异步加载结果。
5. 采集完成后，企业信息会自动保存，不需要再次点击保存。

为了降低官网访问风险，系统默认每家企业间隔约 90～180 秒，每小时最多处理 10 家企业。

## 七、验证码和结果不稳定时怎么处理

如果页面显示“需要验证码”“安全验证”或“查询结果尚未稳定”，且未启用超级鹰自动识别：

1. 在 Edge 官网页面完成验证码或安全验证；
2. 回到项目页面查看具体原因；
3. 点击“验证完成后继续采集”；
4. 系统会重新识别当前页面，不会重复输入或提交企业名称。

如果官网明确显示没有匹配企业，系统会将该企业转为“待审核”。

如果仍然无法识别，可以点击企业行的“人工补录”，将官网企业详情页的文字复制到解析框，点击“解析全部信息”，确认无误后点击保存。

## 八、多个候选企业

当官网返回多个相似企业时，项目页面会显示候选项，通常包括：

- 企业名称；
- 统一社会信用代码；
- 法定代表人；
- 经营状态；
- 注册地址摘要。

使用者选择正确的企业后，系统会继续在后台打开详情页并采集信息。不要根据名称相似直接猜测，应优先核对统一社会信用代码和注册地址。

## 九、查看和导出结果

任务列表中的状态说明：

- 待采集：尚未查询官网；
- 待审核：需要人工补充或确认；
- 存在冲突：官网企业与输入名称不一致，需要核对；
- 已完成：基本企业信息已经确认。

点击“导出结果表”可以导出企业基本信息结果。

点击“查看其余信息清单”可以查看没有映射到主要结果字段的官网信息；点击“导出其余信息清单”可以单独导出这些明细。

## 十、常见问题

### 点击开始后台查询后一直等待验证助手连接

检查以下内容：

- Edge 是否正在运行；
- 是否已经在 `edge://extensions/` 加载 `edge-extension` 文件夹；
- 扩展版本是否为 `0.2.6`；
- 更新扩展代码后是否点击了“重新加载”；
- 项目地址是否为 `http://127.0.0.1:8080/`。

### 官网出现 403、521 或 IP 请求异常

立即停止自动采集，不要连续刷新、重复启动或更换账号反复尝试。系统会进入保护冷却期，默认保护时间为 12 小时。

### 解析出来的信息不完整

这是正常情况之一。官网可能使用分页、折叠栏目、动态加载或不同页面结构。使用“人工补录”粘贴完整页面文字，系统会把无法映射的内容放入“其余信息清单”。

### 重启项目后任务是否丢失

历史任务和已经保存的企业档案保存在本机 `data` 目录中，不会因为重启丢失。正在进行中的验证会话可能失效，需要重新点击“开始后台查询”。

## 十一、安全和合规提示

- 只查询官网公开展示的信息；
- 不要把身份证号、手机号、账号密码或 Cookie 粘贴到项目中；
- 未启用超级鹰时，不要尝试绕过验证码、访问限制或官网安全策略；
- 结果用于工作统计时，应遵守所在单位的数据安全和个人信息管理要求；
- 官网触发访问限制后，应等待冷却，不要通过高频重试规避限制。
