企业信息自动采集

导入企业名单或输入企业名称后，系统会打开国家企业信用信息公示系统。用户仅需在浏览器中完成验证码；唯一匹配的企业将自动采集全部公开栏目，多候选企业才需要人工选择。

一、创建企业任务

支持 CSV/XLSX，按企业名称去重。

二、自动采集任务

后台查询

点击“开始后台查询”后，验证助手会在后台标签页处理官网查询；本页面会展示进度和需要选择的企业候选项。
系统不会读取或上传 Cookie、账号、密码等登录信息。启用超级鹰后，验证码会优先自动识别；识别失败或未配置时自动转为人工补录。

选择企业候选项

官网返回多个候选项。请在此选择正确企业，系统将在后台继续采集。
