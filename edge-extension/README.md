# Edge 企业信息自动采集扩展

当前版本：`0.3.0`

## 安装

1. 在 Edge 地址栏打开 `edge://extensions/`。
2. 打开左侧“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本目录 `edge-extension`。
4. 将“企业信息验证助手”固定到浏览器工具栏。

## 使用

1. 启动本地项目并创建企业任务。
2. 在项目页面点击“开始后台查询”，并保持 Edge 浏览器已启动。
3. 扩展会领取任务，创建一个**后台标签页**访问国家企业信用信息公示系统；不会将官网窗口切到前台。
4. 扩展会对每家企业仅提交一次普通查询，并监听页面变化等待官网异步渲染结果；读取可访问的详情页后发送到 `127.0.0.1:8080` 解析、保存并切换下一家。
5. 如果官网返回多个候选项，项目页面会列出企业名称、信用代码、法定代表人、状态和地址摘要；使用者在项目页面选择正确企业，后台继续处理。
6. 遇到验证码时，扩展会自动截取官网验证码图片并交给本地项目；本地项目启用超级鹰时自动识别并应用结果，识别失败或未配置时项目页面会显示具体原因并等待人工处理。完成官网验证后，点击项目页面的“验证完成后继续采集”，扩展会重新识别当前页面，不会重复提交企业名称。

采集成功后会自动保存，不需要在扩展中再次确认。基本信息已保存但扩展栏目缺失时，任务会进入“待审核”，扩展继续下一家；后续在项目页面使用“人工补录”完善。

扩展固定使用一个后台国家企业信用信息公示系统标签页，防止多个标签页重复输入或重复采集。每家企业完成或转人工后，服务端会随机等待 90–180 秒；默认每小时最多完成 10 家。等待和额度记录保存在本机数据库，重启项目或扩展不会清除。扩展会尝试点击当前详情页可见的“全部展开/展开全部”，但不会自动遍历官网独立分页。

## 更新

扩展文件更新后，在 `edge://extensions/` 页面点击“重新加载”。项目重启后旧验证会话会失效，需要从项目页面重新点击“开始后台查询”。

## 安全说明

扩展不会读取或上传 Cookie、账号和密码，超级鹰凭据只保存在本地项目配置中。扩展仍会遵循服务端访问保护：出现“IP 请求异常”、403 或 521 时，系统会停止自动访问并锁定 12 小时；请不要刷新、重新开始或反复验证。
